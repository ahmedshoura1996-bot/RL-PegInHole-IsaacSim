# RL-PegInHole-IsaacSim

## Overview

This repository contains the implementation of a reinforcement learning framework for robotic peg-in-hole insertion using the Franka Panda robot in NVIDIA Isaac Sim.

The project is developed as part of a Master's thesis focusing on:

- Reinforcement Learning (Soft Actor-Critic)
- Robotic Peg-in-Hole Assembly
- Digital Twin
- NVIDIA Isaac Sim
- Franka Panda Robot
- Autonomous Robotic Manipulation
